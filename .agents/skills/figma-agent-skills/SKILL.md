# Figma Agent Skills

Workflows for inspecting Figma files, extracting design tokens, and converting design specifications into pixel-perfect Flutter widgets.

## Workflows
1. **Design Token Extraction**:
   - Extract color palettes, typography scales, spacing units, and elevation shadows from Figma design files.
   - Map Figma styles to Flutter ThemeExtensions and design tokens.
2. **Component Translation**:
   - Translate Figma frames, autolayout rules, and constraints into Flutter Flex, Column, Row, and Stack widgets.
3. **Asset Handling**:
   - Export SVG vectors and high-DPI raster assets with proper density buckets.
