# GitHub Agent Skills

Runbooks for automating GitHub workflows via git and MCP server tools.

## Workflows
1. **Pull Requests & Code Reviews**:
   - Create clean, atomic commits with descriptive commit messages.
   - Generate release notes, changelogs, and summary diffs.
2. **Issue Management**:
   - Track bugs, reproduce issues, and link commits to GitHub issues.
